# 《明日随访》项目实现文档 · 01 册：核心契约

版本：1.1（2026-09-12）。本册定义领域事实、事件、解锁、谜题和存档。与 02/03 册配套执行；发现矛盾时先修订契约和对应验收，不凭页面需要伪造事件。v1.0 的冲突条目已由 §12 的裁决替代。

## 1. 阶段与分支

主阶段顺序仅包含 BOOT 至 SURGERY_READY。三个结局互斥，不参加大小比较；结局后的旧页面投影先查 ending override，再使用最后主阶段。

```ts
export const MAIN_PHASES = [
  'BOOT', 'R03_PREARCHIVED', 'IDENTITY_RESTORED', 'THEATER_DISCOVERED',
  'DUAL_SOURCE_EXPOSED', 'CLOSURE_PROVEN', 'TRAIL_FORKED',
  'AUDIO_RECOVERED', 'SCOPE_LIMITED', 'SURGERY_READY',
] as const;
export type MainPhase = typeof MAIN_PHASES[number];
export type EndingId = 'A' | 'B' | 'C';
export type GamePhase = MainPhase | `ENDING_${EndingId}`;
export type Scope = 'READ' | 'FACT_ONLY' | 'ENDING';
export type PatientId = 'R01' | 'R02' | 'R03' | 'R04' | 'R05' | 'R06';
export type PuzzleId = 'p1'|'p2'|'p3'|'p4'|'p5'|'p6'|'p7'|'p8'|'a1'|'m7'|'rnm';
export type EdgeId = 'A'|'B'|'C'|'D'|'E'|'F';
export type ConfigId = 'A'|'B'|'C'|'D'|'E'|'F';
export type AudioId = 'AUD01'|'AUD02'|'AUD03'|'AUD04'|'AUD05'|'AUD06'|
  'AUD07'|'AUD08'|'AUD09'|'AUD10'|'AUD11'|'CHANNEL_03_FULL';
export type CardId = 'M-7'|'W-F'|'R-NM'|'U-R';
export type StatementId = `ST_${PatientId}`;
export type EvidenceId = 'EV01'|'EV02'|'EV03'|'EV04'|'EV05'|'EV06'|'EV07'|
  'EV08'|'EV09'|'EV10'|'EV11'|'EV12'|'EV13'|'EV14'|'EV15'|'EV16'|'EV17'|
  'EV18'|'EV19'|'EV20'|'EV21'|'EV22'|'EV23'|'EV24'|'EV25'|'EV26'|'EV27';
export type IdentityRef = `${'EV01'|'EV02'}#${PatientId}`;
export type Empty = Record<string, never>;
export type ReviewCause =
  | { kind: 'SELF'; eventId: string }
  | { kind: 'REPLAY'; archiveId: 'RV_PREV_01' };

  identity: Partial<Record<PatientId, IdentityRef>>;
  intent: Partial<Record<PatientId, StatementId>>;
  chain: 'EV27#NEXT_SHIFT' | null;

```

**提交与拒签只在后续调查能力上等价，行为事实不等价。** SELF 路线具有玩家的 SUBMIT_REVIEW；REPLAY 路线只记录 WATCH_REPLAY，引用一份封存在 `review-source.json` 的历史签认 `RV_PREV_01`。历史事件不得插入玩家日志，更不得标为玩家做过。

两路线都产生系统事件 REVIEW_TRIGGER_OBSERVED，记录 `cause`、被观察到的范围 ENDING，并展示索引结果。阅读回放使玩家看到历史预归档，不造成新的预归档。剧情始终说明：SELF 是实时批次；REPLAY 是护士保存的批次回放，后续操作进入该批次的复查工作区。

## 2. 类型与持久化边界

下列 TypeScript 与 §1 合并可作领域类型起点。事件类型由 EventPayloads 的键派生，不再维护第二份手写联合。枚举不等于运行时验证；§3/§7 的对象、证据归属和前置条件仍需 validator。


所有通关事实、已跑实验、已用提示、已打开文档与已读音频都由事件推导，不在 drafts 中保存第二套权威副本。drafts 仅保存尚未提交的选择；拖动、钉选、输入和设置变化也须保存，不只在追加剧情事件时保存。

## 3. 事件语义与命令事务

共 **52 个事件码**；20 条叙事投影以 02 册 narrative.json 为准，由键集检查数目，取消易失真的手工星标。除下表指定 SYSTEM 的事件外为 PLAYER。scope 由命令处理器固定赋值，不能信任页面传入的任意范围。

| 事件/事件组 | 进入条件、语义或副作用 | scope / 触发方 |
|---|---|---|
| BOOT_SESSION | 新会话首条，一局一次 | PLAYER |
| DOWNLOAD_HANDOVER | 仅表示发起下载，不宣称文件已成功写入磁盘 | READ |
| ACK_HANDOVER_SAVED / OPEN_SNAPSHOT | 玩家确认本地文件可打开，或打开不可变站内快照；任一置 handoverSecured | READ |
| ACK_PAPER_NOTE / ACK_RULES | 纸面抄写可选；须知确认必需 | READ |
| LOAD_SNAPSHOT | 第一次合法进入 P02；仅一条 COUNT=6 | SYSTEM / READ |
| SUBMIT_REVIEW | 已进入 P04，二次确认接受预填结案；SELF 与 REPLAY 二选一 | ENDING |
| WATCH_REPLAY | 完成历史回放内容确认；只读，不暗中代签 | READ |
| REVIEW_TRIGGER_OBSERVED | 同事务引用上条提交或 RV_PREV_01；验证 observedScope=ENDING | SYSTEM / READ |
| INDEX_RECOUNT | 紧随观察事件；SELF 为实时重算，REPLAY 为载入历史重算结果，措辞不同 | SYSTEM / READ |
| PREVIEW_MED_FIX / ACCEPT_MED_FIX / CANCEL_MED_FIX | 只改变发药记录的在线显示；取消恢复，原始签收不被改写 | FACT_ONLY |
| COMPARE_RECORDS | 去重后 ≥2 个已取得证据；排序无关 | READ |
| RECHECK_SUBMITTED / LINK_IDENTITY | 分别满足谜题 p1 与 AUD01 内容确认；LINK 依据 EV01 或 EV02 | FACT_ONLY |
| PLAY_AUDIO / ACK_AUDIO_CONTENT | 播放和内容确认分开；正文可见后点击已读，与听完后确认等价 | READ |
| TIMELINE_SOLVED / TAG_POSTS / MATCH_FLOORPLAN | 验证排序、三个帖子、三个空间匹配，不能仅打开页即完成 | FACT_ONLY |
| CAPTURE_STATEMENT | statementId 必须属于 patientId，且满足 §6 当前陈述解锁；每人去重 | FACT_ONLY |
| OPEN_DOC | documentId 只接受内容注册项，且 eligibility 已成立；取得对应证据 | READ |
| LOAD_CARD | 由卡片解锁从 false→true 触发，一卡一条；导入重放不补发 | SYSTEM / READ |
| INFER_MASQUE / LINK_AUDIENCE | m7 / p3 成功；LINK 引用 ReviewCause，不要求玩家亲签 | FACT_ONLY |
| PROVE_SHARED_SOURCE / INFER_REFRAIN | p4 来源比较与 rnm 接口解释，两个独立事实 | FACT_ONLY |
| RUN_EXPERIMENT / EXPERIMENT_CONCLUDED | 配置只限六种；记录配置而不信任客户端自报结果 | FACT_ONLY |
| INSPECT_SLICE / W07_SEATED | 前者为发现授权语句；后者为剧场阶段的 SYSTEM 标记 | READ |
| FORK_TRAIL | p6 成功，保留原始事件与分支证据，不改既有日志 | FACT_ONLY |
| TOGGLE_PLOT_HINTS / AUDIO_ORDER_SOLVED | 提示层开关只改投影；a1 必须同时证明排序与接续锚点 | READ / FACT_ONLY |
| RECOVER_AUDIO | 重组成功后，在同事务中登记完整录音 | SYSTEM / READ |
| WITNESS_SCOPE | 先确认完整录音内容与固定范围声明；语音不做识别，文字同等有效 | FACT_ONLY |
| ACK_DESK_SPOT | 纸/物件的自我确认，可跳过，不参与 gate | READ |
| SEVER_PREVIEW | 副本演出 A–F 任一后果；不改变正式关系 | READ |
| ASSEMBLE_NEXT_VISIT | p8 通过，保存完整归属槽位；仅准备照护方案，尚未实际接续 | FACT_ONLY |
| SEVER_EDGE / FINAL_SIGN / ACCEPT_ISOLATION | 只能由 P14 的最终命令提交；一局仅一次，见 §5 | 切除/隔离: FACT_ONLY；签认依 choice |
| RESTORE_IDENTITY / PRESERVE_INTENT / OPEN_NEXT_VISIT | 只在结局 C 的成功事务中顺序写入 | SYSTEM / FACT_ONLY |
| ENTER_ENDING | 最终事务末条；A/B/C 与事务内容严格匹配 | SYSTEM |
| PUZZLE_ATTEMPT | 记录实际提交过的选项及反馈键；复盘称“尝试过的解释”，不推断玩家信念 | FACT_ONLY |
| HINT_REQUESTED | 各题三级提示；不参与结局好坏 | READ |
| EXPORT_ARCHIVE / IMPORT_ARCHIVE | 导出含 EXPORT 事件；导入验证后在载入日志末尾追加 IMPORT | READ |

**一个用户动作对应一个命令，一个命令可以提交一个原子事件批次。** 例如 SELF 首次确认批次为 SUBMIT_REVIEW → REVIEW_TRIGGER_OBSERVED → INDEX_RECOUNT。整批生成、整批验证、串行算哈希、一次保存；成功后才更新 UI。reducer 仅折叠日志，不生成任何副作用。

`planCommand(state, command)` 返回 EventDraft[]；`reduce(events)` 返回状态；`validateEvents(events)` 校验 seq、scope、payload、事务结构与可达性。同 commandId 重试复用 txId，不能二次发放卡片/证据。恢复/导入只调用 reducer 和校验器，绝不再次执行 planCommand。

普通已保存日志只能追加。事务在保存前失败就整体放弃；若存储失败，显示真实原因并保留内存状态及导出入口，不把失败写进恐怖剧情。

## 4. 内容投影与原始事实

`resolveContent(entry,lastMainPhase,ending)`：先查 endingOverrides；否则取唯一命中的阶段变体；区间为 **[from, untilExclusive)**。构建时拒绝重叠区间、重复键、未知阶段。不再使用包含式 until，避免姓名恢复和结局 C 文案被旧变体覆盖。

`selectNarrativeTrail` 返回原始事件、系统解释、fact、原始 seq/elapsedMs 和可选 claimedTime。系统声称时间单列且标为“系统摘要时间”；绝不替换事件的 elapsedMs。玩家始终可查看真实顺序，不用“假时钟”制造强制排序谜题。

PLAYER_LOCAL 内容与冻结快照无变体。来源可靠性、来源独立性和保存位置是三回事：EV01/EV02/EV03源自同一交接联，不能算三个独立目击。

P02 的“演员名单”仅做一次缓慢文字替换，8 秒后恢复；这是独立 presentation cue，不使用 phase 区间计秒，不闪屏，reducedMotion 直接省略。seenPresentationCues 保存一次性状态，不影响 gate。

## 5. 状态转移与结局

| 转移 | 从 | 必须已成立的条件 | 到/系统效果 |
|---|---|---|---|
| T0 | 无会话 | BOOT_SESSION | BOOT |
| T1 | BOOT | 合法 REVIEW_TRIGGER_OBSERVED + INDEX_RECOUNT | R03_PREARCHIVED |
| T2 | R03_PREARCHIVED | p1 成功、aud01Read、LINK_IDENTITY | IDENTITY_RESTORED |
| T3 | IDENTITY_RESTORED | timelineSolved、postsLinked、floorplanMatched、masqueInferred、audienceConfirmed | THEATER_DISCOVERED；W07_SEATED |
| T4 | THEATER_DISCOVERED | PROVE_SHARED_SOURCE | DUAL_SOURCE_EXPOSED；解锁 R-NM |
| T5 | DUAL_SOURCE_EXPOSED | refrainInferred、EXPERIMENT_CONCLUDED | CLOSURE_PROVEN |
| T6 | CLOSURE_PROVEN | sliceInspected、FORK_TRAIL | TRAIL_FORKED |
| T7 | TRAIL_FORKED | AUDIO_ORDER_SOLVED、RECOVER_AUDIO | AUDIO_RECOVERED |
| T8 | AUDIO_RECOVERED | recoveredAudioRead、WITNESS_SCOPE(FACT_ONLY) | SCOPE_LIMITED |
| T9 | SCOPE_LIMITED | 预览过 D 或 F；ASSEMBLE_NEXT_VISIT(p8 验证) | SURGERY_READY；只置 carePlanReady |
| T10A | SURGERY_READY | 最终命令 chooseEnding(A) | FINAL_SIGN(ENDING) → ENTER_ENDING(A) |
| T10B | SURGERY_READY | 最终命令 chooseEnding(B)，已预览 F | SEVER_EDGE(F) → ACCEPT_ISOLATION → ENTER_ENDING(B) |
| T10C | SURGERY_READY | 最终命令 chooseEnding(C)，已预览 D，FACT_ONLY | SEVER_EDGE(D) → FINAL_SIGN(FACT_ONLY) → RESTORE_IDENTITY → PRESERVE_INTENT → OPEN_NEXT_VISIT → ENTER_ENDING(C) |

所有结局仅从知情最终面板进入；A/B 不产生 OPEN_NEXT_VISIT。结束后拒绝一切改变照护结果的命令，仍允许浏览、导出、复盘、设置。欲体验其他结局，载入玩家之前导出的决策前存档或开新局，不静默撤销已签事件。

## 6. 完整开放矩阵

页面重定向只是 UI 保护；每个领域命令也必须校验相同条件。已解锁内容在后期保留可读；首次解锁不是页面自动完成。P00 永远可访问。

| 页面/内容 | 首次可访问条件 | 下一步 / 取得条件 |
|---|---|---|
| P01 | 已有会话 | handoverSecured ∧ rulesAcknowledged 才能去 P02 |
| P02/P03/P04 | handoverSecured ∧ rulesAcknowledged | P04 在触发分支选定后仅回看，禁止第二次签认/切换路线 |
| P05 发药标签 | phase≥R03_PREARCHIVED | p1→AUD01→LINK_IDENTITY |
| P05 时间线标签 | r03IdentityRestored | p2；材料引用 §7 与 02册 timeline.json |
| P06 | r03IdentityRestored | 三帖正确关联才置 postsLinked；不靠打开页面解锁 |
| P07 | postsLinked | 平面图可读；M-7还需 timelineSolved；W-F还需 masqueInferred |
| P08 | phase≥THEATER_DISCOVERED | p4后 R-NM 可读；rnm 是进入 P09 的必要事实 |
| P09 | dualSourceProven ∧ refrainInferred | p5 |
| P10 | experimentConcluded | INSPECT_SLICE |
| P11 全屏工作台 | sliceInspected | p6；轨迹抽屉从 P01 起可看，抽屉不受此门槛限制 |
| P12 | trailForkCreated | U-R可读；a1→完整录音确认→本地见证 |
| P13 | witnessScope=FACT_ONLY | p7副本预览；不执行正式切除 |
| P14 | witnessScope=FACT_ONLY ∧ 预览过 D或F | p8及全部正式结局动作；不必返回 P13 |

## 7. 谜题、推理支撑与判定

编号沿用 p1–p8，另将录音重组正式编号 a1；m7/rnm 为两项简短判断。共九个谜题和两项判断。每题都保存草稿、提供三级提示（02册 hints.json）及具体冲突反馈。输入是语义选项/对象引用，不做自由文本字符串全等。

所有被提交的证据必须已经取得，不能仅因ID存在于内容包就接受。必需材料在当前谜题页提供合法打开入口：p2包含EV05/07/10/11；p3包含EV15/16/05/10及已解锁W-F；p4包含EV19/20；rnm包含EV22与R-NM。结果型证据不作为自己生成的前置条件。

### p2 时间线重排

### m7 封闭结构判断

### p3 谁在确认终局

### p6 轨迹异议

三个槽是**调查里程碑**，不是伪造的历史时钟：SNAPSHOT_LOADED → REVIEW_CAUSE_OBSERVED → IDENTITY_LINKED。中间槽引用本局 REVIEW_TRIGGER_OBSERVED，再追溯SELF或REPLAY原因。原始seq可见，排序是校验步骤，主要难点是给错误叙述提出有证据的异议。

关联要求：SNAPSHOT_LOADED需EV01或EV02；REVIEW_CAUSE_OBSERVED需EV05+EV10；IDENTITY_LINKED需EV12，以及本局LINK_IDENTITY事件（EV03只能作为附加纸面旁证）。还需指出 `UNSUPPORTED_ENDING`：护理事实不支持关于人生终局的结论。

**日志 scope 一直是 ENDING，不曾从 FACT_ONLY 被偷偷改写。** 异常在于系统把一次预填结案解释为“没有后续生命事项”，超出已有事实的支持范围。拒签路线指出的是历史签认的解释问题，不承认自己签过。

### a1 交班录音重组

## 9. 哈希链与事务验证

`canonical(event)`为对**除hash以外全部事件字段**进行stableStringify的JSON：对象键排序、数组保序，拒绝undefined/NaN/Infinity及未知字段。包含previousHash、scope、payload、actor、id、seq、elapsedMs、txId。首条previousHash=null；使用crypto.subtle的SHA-256，hex小写。不使用拼接分隔符，避免payload包含分隔符导致歧义。

用途是提供游戏内轨迹一致性，不声称能抵御玩家自己修改网页与重算哈希。生产目标为HTTPS与localhost；不再增加第二套FNV散列及其迁移负担。无Web Crypto时保留读取已有档案和提示更换运行入口，不静默改算法。

校验包括哈希完整性、seq连续、elapsedMs非递减、唯一id、txId块连续、系统事件来源、命令批次完整、结束后无结果突变、证据引用合法。导出导入回环比较的是追加IMPORT前的日志前缀，不能要求整个数组完全相等。

id=`${sessionId}-${seq}`；seq从1开始；elapsedMs为非负整数且不大于存档elapsedActiveMs；txId来自命令的幂等标识。导入不得重写已有id或主体，只能追加新的导入事件。

## 10. 存档、导入与设备

| 存储 | 键/库 | 内容 |
|---|---|---|
| localStorage | cw-save-v2 | 完整SaveData，单次setItem提交完整事务 |
| localStorage | cw-settings-v1 | SettingsData，与剧情独立 |
| IndexedDB | cw-audio / witness | id、mime、blob、createdAtMs；录音可独立删除 |

elapsedActiveMs在可见、非暂停、非P00时累计；恢复以保存的时钟继续，不能只用末条事件时间。draft变更200ms内保存，隐藏/退出时同步刷新草稿；已提交剧情事务不节流。lastRoute只记合法游戏路由，P00不覆盖它，恢复时仍须重验开放条件；不能接受导入中的外部URL。叙事“次日”为单独故事日期标签，不把真实elapsedMs跳一天。

持久写操作持有 `navigator.locks` 的 `cw-save-writer` 独占锁，并在锁内比较sessionId/revision/末条hash。若外窗版本已推进，取消当前命令并进入只读提示，用户可重新载入；不能合并两边日志。BroadcastChannel/storage仅通知，**不能充当锁**。缺Web Locks或存储写入失败时，提供明确的本窗口临时游玩模式及导出，不承诺刷新可恢复；已有持久存档不被覆盖。Web Locks能力来源见04册。

本地录音：说明→请求→开始→停止→可重录/试听→确认固定范围声明。按住和点击开始/停止两种操作均可，Esc/pointercancel/页面隐藏均终止轨道。限60秒，静音不判错，不识别发音；保存失败时允许用相同文字声明继续。所有轨道在停止、拒绝、异常、离页时释放。

WitnessRecord始终保留canonicalText；语音只提供个人留证，不能让“说了什么”成为隐藏gate。导出不含blob，保留正文与引用并将副本recordingAvailable=false；导入不伪装恢复了录音。删除音频blob不撤销已经确认的FACT_ONLY事实。清除全局进度与清除录音分别操作。

导出：先完成EXPORT_ARCHIVE事务，再将ExportData生成文件；下载成功由玩家检查，不通过浏览器不可观测的保存结果自动判定。导入：先检查大小（文本上限10MiB）、JSON/schema/contentVersion、哈希和领域合法性，再预览会话与进度并确认覆盖；失败不触及当前进度。所有导入文字按纯文本渲染。

v1.0文档的schemaVersion=1缺少分支来源与内容确认事实，**不自动伪造事件升级为v2**。保留原文件，明确不兼容，可另开v2新局；若已存在实际v1存档，后续先取真实样本再编写迁移器。未知更高版本明确拒绝。移除没有实现依据的“从最近章节自动重建”承诺。
