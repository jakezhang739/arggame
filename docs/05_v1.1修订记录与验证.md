## 4. 继续实施时如何使用

先读00册范围与01册相关契约，再按04册依赖选择子任务。可以先完成M1，再决定需要怎样打磨医院界面、照片和配音。02册每个JSON块的文件名就是后续src/content中的目标名；提取后应运行内容检查，不手动维护另一个答案版本。

新实施采用schemaVersion=2。若已经有真正的v1存档，先保留原件，再依据实际样本另做迁移；不要为了让旧进度“看起来兼容”而伪造玩家签认、听读或当前意愿采集事件。

外部原文和浏览器能力出处已放入02/04册。旧源稿如与v1.1冲突，以本轮修订后的明确规则为准，同时在后续变更记录中说明调整；正常修复不需要每完成一个任务就重新询问用户。
