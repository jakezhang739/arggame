# 《明日随访》UI 视觉基线

## 1. 总基调

**冷静的机构档案界面，带轻微年代感和受控异常。**

玩家首先应该相信这是一套仍在值班的康复中心内部系统，其次才逐渐意识到记录之间存在问题。界面不靠黑底、血色、故障闪烁制造恐怖；不安来自正常流程里的错误关系、被改写的措辞和能够对照的原始证据。

三个感受关键词：**可信、安静、可追溯**。

视觉材料来自夜班场景中的真实质感：冷灰绿墙面、深绿金属台面、暖色旧纸、氧化黄标签、低亮度值班灯。布局保持现代网页的清晰度，不模仿真实操作系统，也不做妨碍阅读的重度做旧。

## 2. 视觉层级

1. **结构层**：灰绿背景、白色工作面、细边框，承担稳定与可信感。
2. **行动层**：深绿只用于主操作、当前状态和明确的可交互内容。
3. **提醒层**：氧化黄用于待处理、范围说明和需要谨慎阅读的内容。
4. **异常层**：暗红只用于证据冲突、被改写内容和不可逆警告；常规页面不得大面积使用。
5. **叙事层**：旧纸、宋体标题和台灯照片只在档案或记忆语境中出现，不覆盖业务信息。

## 3. 四套系统皮肤

| 系统                | 视觉语境       | 保留特征                           |
| ------------------- | -------------- | ---------------------------------- |
| 院内系统 `CW·INTRA` | 冷灰绿业务系统 | 清晰表格、状态统计、深绿主操作     |
| 病友论坛 `CW·BBS`   | 低饱和社区镜像 | 较松的阅读节奏、柔和卡片、几何头像 |
| 地方档案 `CW·ARC`   | 暖纸馆藏索引   | 宋体标题、米色纸面、棕色索引线     |
| 审校实验室 `CW·LAB` | 冷色归档工作台 | 细网格背景、等宽数据、图文并列     |

四套皮肤共用同一顶部身份栏、按钮形态、焦点样式、内容宽度和间距体系。换皮肤只改变语境，不改变玩家对操作规则的预期。

## 4. 核心规范

- 主内容最大宽度 `1180px`，桌面两侧留出稳定呼吸空间。
- 正文使用中文无衬线字体，文书或档案标题可使用宋体；编号、来源和时间使用等宽字体。
- 主标题前使用短色条作为章节定位，不使用大面积渐变标题或装饰性英文字。
- 卡片保持浅色实体表面、细边框和极轻阴影。阴影只表达层级，不制造悬浮玻璃感。
- 按钮至少 `40px` 高；主按钮为深绿实底，普通按钮为浅底描边，危险按钮为暗红。
- 圆角以 `4px / 8px / 14px` 为限，避免消费级应用的大胶囊化。
- 焦点始终使用蓝色 3px 实线，不能只依赖颜色变化。
- 移动端优先保证任务可完成：表格转卡片，双栏转单栏，轨迹入口固定在右下角。

## 5. 图像与动效

- “护士站旧台灯”是项目主视觉锚点，可用于入口与交接语境；图像不藏线索，不承担谜题验证。
- 图像保持低饱和冷绿环境与一处暖光，不出现人物、血迹、灵异形象或紧急医疗场面。
- 异常表现只允许轻微文字改写、删除线、局部颜色和状态变化；禁止闪屏、强制全屏、抖动或突然高音量。
- 所有动画都应短促、可预测，并尊重 `prefers-reduced-motion`。

## 6. 禁用方向

- 全站黑底红字、赛博朋克霓虹、扫描线堆叠或重度 CRT 故障。
- 把每个信息块都做成独立彩色卡片，导致证据层级失焦。
- 大量无意义图标、Emoji、玻璃拟态、超大圆角和高饱和渐变。
- 用氛围照片替代可访问文字、数据列表或明确操作。
- 为了“恐怖感”降低对比度、隐藏焦点、延迟按钮或制造误触。

实现中的颜色、间距、圆角和阴影统一从 `src/assets/styles/tokens.css` 取值；新增页面应优先复用 `.panel`、`.notice`、`.badge`、`.button` 和既有系统布局。
