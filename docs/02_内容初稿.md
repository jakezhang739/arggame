# 《明日随访》项目实现文档 · 02 册：内容初稿

版本：1.1（2026-09-12）。保留六人病历、台灯意象、四部坡作品和三结局。以下15个JSON块均为严格JSON，可按标题文件名直接落盘；条件键含义由01册开放矩阵解析，不使用eval执行字符串。

文风：医院文书克制，异常从记录差异、身份关系和时态出现。原始证据不直接宣布推理结论；玩家完成比较后生成的结果卡可以总结发现。正文中的实现注记不渲染为角色台词。

开局医院只展示迁移、签收、护理和版本管理等普通流程。不要在P01提前解释“叙事轨迹比系统可靠”“这是心智支柱”等术语；轨迹控件可见，但其意义随调查逐步建立。

## 16. 内容量与节奏验收

不再用JSON总字数推算游玩时长：重复的病例、录音字幕、证据引用与结局复盘必须去重。v1.1的新增内容主要用于补齐因果材料和可操作线索，不靠延长静默或强制阅读计时凑时长。

| 段落 | 目标分钟 | 玩家完成的认知变化 |
|---|---:|---|
| 交接、签认/回放、找回许棠 | 30–40 | 表格数量错误→人的身份关联被覆盖 |
| 时间线、论坛、剧场与M-7/W-F | 35–40 | 异常地点→需要外部见证的流程 |
