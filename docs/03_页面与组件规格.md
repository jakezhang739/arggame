# 《明日随访》项目实现文档 · 03 册：页面与组件规格

版本：1.1（2026-09-12）。4套布局、8个共享叙事组件、17个页面。所有正文来自02册；开放、事件、正式结果以01册为准。本册补齐进入条件、离开方向、空态与恢复行为，开发不再依赖两份旧源稿的页面地图。

## 1. 全局骨架与视觉

真实浏览器地址栏始终可见。页面顶部为虚构系统标识与四个稳定控件：退出、设置、字幕、活跃时长。退出返回P00并暂停时钟；不弹剧情式拦截。P01之后始终有可聚焦的轨迹按钮。P11/P15/P16不显示虚构地址，但保留稳定控件。

| 布局 | 站内标识 | 布局与视觉 |
|---|---|---|
| HospitalLayout | intra.chengwan | 浅灰绿院内业务系统；宽表格、常规表单、状态栏；异常前不要做恐怖标题与红黑配色 |
| ForumLayout | bbs.chengwan.help | 旧论坛帖子流；头像为几何形；较松散的阅读间距 |
| ArchiveLayout | archive.chengwan.local | 淡纸底、宋体标题、清晰文件索引；不加妨碍阅读的做旧纹理 |
| LabLayout | lab.chengwan | 深浅层次明确的工作台；图与文字列表并列，数据等宽 |

以上字符串仅为游戏标签，不是实际外部域名或请求地址。FakeAddressBar使用圆角标签，不画浏览器窗口按钮或原生锁图标；提示“游戏内系统视图”。布局主内容最大宽1240px，正文16px/1.7；文书可用18px/1.8。桌面轨迹抽屉宽340px，可收起；≤768px用全屏覆盖层，退出/关闭按钮保持可用。

| token | 值/约定 |
|---|---|
| background / surface | #F3F6F3 / #FFFFFF |
| text / muted | #1F2D29 / #53645D |
| primary / border | #245A48 / #CBD5CF |
| warning / error | #805600 / #9F3030，同时配图标与文字 |
| archive background | #F6F1E7 |
| focus | 3px实线#225DA8，外偏移2px |
| spacing / radius | 4/8/12/16/24/32px；4或8px |

颜色需在实现后的真实组合中检查对比度，不能仅凭token表宣称通过。200%字体可回流；手机病历表变卡片，实验结果表提供可读列表。渐显/折叠遵循reducedMotion；无闪屏、闪灯、突然高音量或强制全屏。照片不用作验证线索。

定位约定：稳定业务对象使用 `data-testid="p02:patient-row--R03"` 等；语义明确的按钮优先getByRole/getByLabel。文本断言允许且必要，尤其计数、范围说明和最终按钮。不要全站禁用语义选择器或把aria仅当测试标签。

## 2. 八个共享组件

| 组件 | 输入/状态 | 必须提供的行为 |
|---|---|---|
| NarrativeTrail | mode=drawer/full；selectNarrativeTrail | 系统叙述与原始事实对照；展开真实seq、对象、来源、范围；系统声称时间独列；无Ctrl+T快捷键冲突 |
| EvidenceBoard | 已取得证据、pinnedEvidence | 按来源/时间筛选，钉选与取消，显示来源树；未知时间显示未记录；不显示supports或未取得证据答案 |
| SourceInspector | evidenceId/documentId | sourceId、originGroup对应说明、派生关系、版本；不同模块可来自不同原始过程；不把所有来源硬连同一根 |
| VersionDiff | 左右原稿、标记选项 | 同步滚动可选；键盘选错字/原稿号等；手机切换左/右，保留固定对应行标题，不强制两块60%宽挤屏 |
| AudioFragment | audioId、timings、peaks | 播放/暂停/重播、客观字幕、波形、可关解释层；只有用户点击才出声；全局单音源；无音轨也能读客观信息 |
| LocalWitness | witness草稿、录音可用性 | 说明→录制/文字→试听或预览→范围确认；点击开始/停止与按住等价；释放MediaStream；拒绝/失败转文字；固定声明总保留 |
| GameDialog | speaker、lines、mood | 点击/空格下一行；允许立即展开完整段落；无强制逐字等待，reducedMotion不渐显 |
| FakeAddressBar | 虚构系统标签 | 纯装饰导航上下文；不承诺实际联网或域名真实性，不模仿浏览器原生chrome |

Hints、稳定控件、病历表等可以使用普通局部组件；“8个”指上述共享叙事组件，并非禁止合理拆分代码。轨迹抽屉通过可见按钮、Tab与Esc操作，不劫持浏览器常用快捷键。

## 3. 全页面流程与开放条件

开发用页面编号；玩家界面不显示P00或谜题p1等工程名称。router守卫、按钮禁用理由与领域命令共用01册条件。内容已解锁后可回访；任务导航显示尚缺事实，不替玩家填写答案。

### P00 开始/恢复 `/#/`

- 中央登录卡：“外部复核终端／等待交接”。预计180–240分钟，可分次完成；纸笔和耳机可选；声音与麦克风均有文字替代；虚构作品与本机保存说明可展开。
- 新局→BOOT_SESSION→P01；有存档时继续为主按钮；导入先预览会话与版本；新局覆盖旧进度前先提供导出。
- 声音测试必须点击触发；设置可调整字幕、音量、字体。缺持久存储时明确说明“本次仅此窗口保存，退出前可导出”，仍允许临时游玩。
- 进入P00暂停活跃时钟。继续打开上次合法页面；非法/旧路由按01册当前阶段首页处理。
- 验收：纯键盘启动；导入失败保留原存档；不能把坏存档/资源失败当成谜题。

### P01 迁移交接 `/#/migration`

- 进入：会话存在。步骤①保存交接联；②可选纸面抄写；③确认v3.2六条须知。
- 下载发DOWNLOAD_HANDOVER，仅表示发起。下面始终并列“我已打开保存的文件”→ACK_HANDOVER_SAVED与“打开只读快照”→OPEN_SNAPSHOT；不等待前端无法可靠检测的系统保存完成。
- 纸面抄写R03、许棠、台灯句，自己做记号；ACK_PAPER_NOTE为自证。跳过没有负面提示或隐藏惩罚。
- ①任一保障方式成立且须知确认→“进入随访平台”。照片使用护士站旧台灯的安静画面，不闪灯。资料原文只提示保留矛盾，不提前讲叙事污染机制。
- 验收：仅快照、无纸面也可继续；EV01仅在确认本地保存后取得，EV02在快照打开后取得，不能默认都算已取得。

### P02 随访总览 `/#/followup`

- 进入：handoverSecured∧rulesAcknowledged。首次合法进入由命令层完成LOAD_SNAPSHOT，六行名单、在册6、待复核1。
- SELF签认或REPLAY观察后，显示该批COUNT=5；R03保留空白行和“记录关联缺失”的可访问名称。搜索许棠结果为0，但可从原始证据或异常导航进入P05。
- IDENTITY_RESTORED恢复六行及许棠姓名，注明原始来源；只恢复关联，整批状态仍待复核。
- THEATER_DISCOVERED后首次回访可缓慢将列表标题换成“演员名单”，8秒恢复；CLOSURE_PROVEN出现W07第七行。两者分开，不自动假定玩家当时在此页。
- ENDING_A在册0；B为六行封存；C恢复六人及后续随访6。原始COUNT事件不随投影改变。
- 验收：刷新不再次发LOAD或INDEX；标题演出不重复；R03阶段边界恢复正确。

### P03 患者详情 `/#/followup/patient/:id`

- 进入同P02；参数仅R01–R06。身份、临床观察、护理事项、本人表达、来源与历史版本；R03事实与授权说明打开时取得EV05。
- R03按content-entries变形：姓名缺失→恢复关联→陈述被摘要改写→C恢复原话；可对照原始版。
- 当前陈述采集：R01/R02随postsLinked；R04随剧场揭示；R05随同源揭示；R06随实验证明。各项出现后需点击“保留这条本人陈述”才发CAPTURE_STATEMENT。新事项由院内“待补交班事项”导航提示，不要求猜哪人更新。
- R03有效当前意愿来自P12完整录音；此页不把被污染摘要当成ST_R03发放。
- 验收：不能通过直接输入URL提前取未解锁陈述；已采集标记可恢复，病历原始数据不被清空。

### P04 外部复核 `/#/followup/review/R03`

- 进入同P02；已有reviewCause后仅能回看。左侧护理事实，右侧预填康复结案；底部授权说明清楚可展开。
- “完成单份复核”先展示接受预填结案的范围，再确认：SUBMIT_REVIEW→REVIEW_TRIGGER_OBSERVED(SELF)→INDEX_RECOUNT，同事务提交，返回P02。
- “先不签，查看保存的回放”始终可见：回放明确署名W06、历史时间和ENDING范围。确认已看→WATCH_REPLAY→REVIEW_TRIGGER_OBSERVED(REPLAY)→INDEX_RECOUNT，进入历史批次复查视图。每次出现计数或原因都标清来源。
- 不把玩家打开回放描写为其签署终局。后续p3/p6都可引用RV_PREV_01。后期范围演示可展示FACT_ONLY对照，但不对已发生的历史事件改scope。
- 验收：两路线都能通到三个结局，而不仅在P05看上去汇合；双击不会造成双签。

### P05 发药对照/时间线 `/#/medication`

- 进入：R03_PREARCHIVED。默认“发药对照”，时间线标签在身份恢复后开放。
- 原始签收、当前索引、实物交班、去向、车次、事务日志、离院报告逐份打开取得；证据板不预先展示未打开的结果。
- 助手建议把第六份签收改成损耗；先预览再接受/撤销。两个分支都保留原始EV06；顶部同时显示原始层与在线修正层，防止玩家以为不可逆失去证据。
- p1提交异常与证据。失败指出缺名单基线、缺后续在场证据或同源重复；成功打开AUD01。字幕全文可见后“已确认这段内容”发ACK_AUDIO_CONTENT；据已取得EV01/02恢复R03身份。
- 时间线使用02册timeline.json五份完整材料，事件时间与上传时间分别显示；REPLAY用历史时钟，SELF用本局事件时间并标明在交接之后。p2还需标EV11不可靠。
- 完成时间线后去论坛；若先读论坛，任务导航仍能回时间线，M-7未提前开放。
- 验收：EV01+EV02不通过p1；EV02+EV06可通过；字幕不播放也可恢复许棠；p2草稿刷新保留。

### P06 病友留言板 `/#/forum`

- 进入：r03IdentityRestored。三段梦境帖与普通康复/维修/家属帖子混排，标题不直接写“线索”。
- 玩家把三个梦境帖关联，使用地点/结构/角色标签。错选普通帖给出具体不对应的信息，不移除正常阅读价值。
- TAG_POSTS成功→postsLinked→开放P07；R01/R02的本人表达允许主动采集。林闻只说她看到的差异，不直接宣布所有人做同一个梦的答案。
- THEATER_DISCOVERED后作者显示“已离院用户”，来源检查仍能核对原发帖人。污染不删除原帖子。
- 验收：成功关联验证三原帖而非任意三个；两条当前陈述分别归属正确患者。

### P07 地方档案与研究卡 `/#/archive`

- 进入：postsLinked。区域一旧剧场图与医院图；二M-7；三W-F；四后期卡片回看。
- 两图固定共同基址：SVG viewBox 0 0 1000 700；外墙矩形(80,60,840,580)；病房/后台在左(100,120,230,400)；护士站/提词位在(360,250,100,100)；复核终端/外席在(690,470)。图例、文字位置表和滑杆等价可用。数字用于工程制图，不是密码。
- OPEN_DOC(THEATER_MAP)取EV15。玩家明确配对病房/后台、护士站/提词位、复核终端/外席→MATCH_FLOORPLAN→EV16。拖透明度本身不算完成。
- M-7需timelineSolved，EV17架构/审计可打开；选择内部结构假说并提交空间证据。成功后W-F开放。
- p3三联：观众确认行为、外席位置、本批实际签认来源。SELF选玩家事件；REPLAY选W06历史事件。满足T3后第七排中央标W07，EV18可打开。
- R-NM在dualSourceProven后开放；U-R在trailForkCreated后开放。原文站外入口始终附默认可用的本站短摘录，不做“3秒判断第三方外链是否打开”的不可实现检测。
- 验收：M-7/W-F不会只因相同phase同时解锁；图+列表得出相同结论；两条原因路径都能成功。

### P08 平行复核 `/#/compare`

- 两文档先展示各自观点与未经解释的原始字段；打开分别取得EV19/20。SourceInspector和VersionDiff允许标错字、导出批次、SOURCE_ID；不凭不存在的第三份原稿要求玩家找缺句。

- 验收：只滚到底、只看卡片或只知道两页同源都不会跳过接口解释；手机能对照同一段。

### P09 单变量实验 `/#/lab/experiment`

### P10 处理切片 `/#/lab/slices`

### P11 轨迹异议 `/#/trail`

- 进入：sliceInspected。三栏：系统解释、不可变原始事件、已取得证据。小屏逐栏切换，并显示当前对应里程碑。
- 三槽为快照载入、观察到预归档原因、恢复身份；原始顺序可见，不靠伪造时间让玩家猜。
- 核心操作是“这句解释是否由事实支持”：链接快照证据、授权说明+真实事务、护士留言+LINK事件，指出UNSUPPORTED_ENDING。REPLAY中因果链接清楚跨到历史档案，玩家自己的观察事件保留READ。
- 成功保存异议分支，系统版本与W07版本并排；实际日志不被改写。系统把“阅读回放”说成“接续见证”时，原始fact明确说明未签。
- 验收：没有玩家SUBMIT的REPLAY能成功；scope从头到尾未被改写；草稿、证据链接刷新保留。

### P12 交班录音台 `/#/audio/channel-03`

- a1需排序并提交三对连续声响接续，不能仅选择“关闭提示”就通过。正确反馈先播放或展示完整交班，再让玩家确认已读，发ACK_AUDIO_CONTENT(CHANNEL_03_FULL)、取得EV25；随后主动保留ST_R03。

- 验收：纯文字、拒麦、录音保存失败转文字都可进SCOPE_LIMITED；录音文件名与波形映射唯一；离页停止所有轨道。

### P14 下一班与最终处理 `/#/handover/next`
