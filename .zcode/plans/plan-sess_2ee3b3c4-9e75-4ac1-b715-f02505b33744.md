## 写作要点

- **内容初稿补全范围**：五人（陈桥/宋渺/何川/邹宁/程枝）的完整病历与承接事项、27 条证据正文、被改写版值班须知、四张研究卡 200–250 字文案、归档助手全台词、三结局旁白——全部直接写成可用文本，嵌入 JSON 代码块，实现时直接提取为 `src/content/*.json`
- **AI 代理工作协议**（写入 00 册）：一次只做一个任务块；契约（01 册）与内容（02 册）是单一真相源，页面规格（03 册）与契约冲突时以契约为准；每块完成后跑验收命令；禁做事项集中汇总（不改历史事件、不伪造浏览器 UI、不用颜色/音频作唯一线索等，源自方案 §4.8/§11）
- **TTS 管线**：给出推荐方案（edge-tts 类免费脚本化工具 + 中文声线分配三人 + Web Audio/CC0 环境声合成）与备选，波形峰值 JSON 用构建脚本预生成；真人替换流程预留
- **测试**：Vitest 覆盖 reducer/gates/存档迁移/哈希链；Playwright 跑 A/B/C 三结局标准存档路径；人工检查清单（Safari 录音回退、200% 字体、键盘排序等）
